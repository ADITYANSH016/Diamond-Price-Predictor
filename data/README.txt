This folder stores the dataset:
- diamonds.csv   → auto-generated on first app launch (5,000 rows)

To regenerate manually:
  python src/data_generator.py

To use the real Kaggle dataset instead:
  1. Download from https://www.kaggle.com/datasets/shivam2503/diamonds
  2. Place diamonds.csv in this folder
  3. The app will use it automatically
